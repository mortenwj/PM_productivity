# Outputs

Generated artifacts from toolkit scripts and skills. **Not** committed by default (`outputs/**/*` is gitignored).

| Subfolder | Typical files |
|-----------|-----------------|
| `morning/` | `morning_report.md` |
| `portfolio/` | `module_health_YYYY-MM-DD.md` (Module Health Scorecard) |
| `pfr/` | PFR / impacted-module analysis markdown |
| `reports/` | Bug quality reports, revenue leaderboard |
| `archive/` | Historical snapshots (from `_archive/`) |
| `scratch/` | ADO/MCP scratch JSON and text |

Specs and generators live under **`toolkit/`** and **`projects/process-platform/pilot/tools/`**, not here.
