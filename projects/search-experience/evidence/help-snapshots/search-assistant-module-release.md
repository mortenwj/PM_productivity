# Search Assistant — new module (help snapshot)

**Source:** https://help.360online.com/Release_information/Index.html#!Documents/newmodule2.htm  
**Captured:** 2026-07-08

## Highlights

- NL prompts → precise structured criteria; built on **Advanced Search**.
- Search across cases, documents, files, projects, employees, etc.
- Sorting, grouping, column selection; results → saved searches.
- Org custom search templates.
- Two menu items at bottom of Advanced Search when enabled.
- Modules: Search assistant + Statistics and counting.
- "Natural-language input is always converted into a clear, auditable query."

## Why it matters (vendor text)

- Faster searching
- Cross-entity insight
- Less manual work for QA/registrar
- Reliable and transparent
