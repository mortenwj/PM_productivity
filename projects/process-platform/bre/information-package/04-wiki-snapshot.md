## Flexibility initiatives — extract

> The Business Rules Engine (BRE) will allow Public 360 users to define, manage, and invoke business rules across the platform in a no-code interface. Rules can be triggered through the web interface, integrated into workflows, or invoked via API calls.

**Listed capabilities:** no-code builder; rule types; invocation (UI, workflow, API); contextual inputs; prioritization/conflict handling; version control; auditing; extensibility; API access.
