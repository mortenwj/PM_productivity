Setup the standard application process

**Wiki (canonical):** [360° Flow - Demo setup](https://wiki.software-innovation.com/wiki/360%C2%B0_Flow_-_Demo_setup)

1. Activate feature toggles NVE and ProcessModelImportExportEnabling
2. Disable Feature toggle FFUI.CaseCreation
3. Enable feature toggle EnableChecklistsP360
4. Activate checklists: Settings -> [checklist.updatechecklist](https://test-dan.public360online.com/locator/Admin/Setting/Details?Id=checklist.updatechecklist)
5. Import process model
6. Import checklist
7. Activate Major Deficiency letter document category; import matching `prosess_mangelbrev` / `process_deficiency_letter` / … template (see wiki ZIP)
8. Activate Decision document category; import matching `prosess_vedtak` / `process_decision` / … template (see wiki ZIP)
